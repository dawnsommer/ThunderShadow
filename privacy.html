Privacy Policy

Last updated: August 8, 2026

ThunderShadow is a browser-based study and error-logging application. Study data is stored locally in your browser by default. Optional Google Drive app-data synchronization is available only when you choose to connect Google.

1. Local browser data

ThunderShadow stores forms, logged entries, reasoning notes, rules, settings, backup metadata, and deletion records primarily in IndexedDB. The application remains usable without signing in or enabling cloud synchronization.

2. Google connection

If you choose Connect Google, ThunderShadow redirects through the shared Cloudflare Worker to Google OAuth and requests only the drive.appdata scope. This scope permits access to application data stored in Google Drive's hidden app-data area; it does not permit ThunderShadow to browse ordinary visible Drive documents, Gmail, Contacts, Calendar, or Google Photos.

The browser stores a Worker session token so it can request short-lived Google Drive access tokens without repeated login prompts. Google refresh tokens and Google client secrets are not stored in ThunderShadow frontend storage.

3. Google Drive app-data synchronization

When cloud sync is enabled, ThunderShadow stores synchronized forms, logged entries, rules, settings, review history, and deletion metadata in your Google Drive appDataFolder. ThunderShadow uses an app-specific file namespace and does not intentionally place these files in your visible Drive folders.

4. OAuth service

The Cloudflare Worker is used only to complete Google OAuth, maintain the server-side refresh-token session, issue temporary Google access tokens to the connected ThunderShadow browser, and disconnect that session. Authentication tokens are not included in Drive synchronization files.

5. Authentication persistence

The Worker session token may remain in browser storage so ThunderShadow can silently refresh temporary Drive access after closing and reopening the app. Disconnecting Google clears that local session state; clearing browser/site data can also remove it.

6. Sharing, advertising, and AI

ThunderShadow does not sell or rent synchronized user data and does not use it for advertising or data-broker purposes. The application does not send your ThunderShadow study database to an external AI service. GitHub Pages, Cloudflare, Google OAuth, and Google Drive may process technical information according to their own service policies as required to host, authenticate, and synchronize the application.

7. User control and deletion

You can use ThunderShadow without cloud sync, sign out at any time, delete local data within the application, or clear the site's browser storage. Disconnecting Google does not delete Drive app-data files. Synchronized Drive records remain until ThunderShadow deletion synchronization or another user-controlled removal process deletes them.

8. Security

ThunderShadow uses HTTPS when deployed through GitHub Pages. Cloudflare Worker, Google OAuth, and Google Drive communications are transmitted using encrypted HTTPS connections. You remain responsible for securing access to your device, browser profile, Google account, and exported backup files.

9. Changes

This policy will be updated if ThunderShadow materially changes the data it collects, stores, or synchronizes.

10. Contact

For privacy questions, use the developer contact information published with the ThunderShadow project.
