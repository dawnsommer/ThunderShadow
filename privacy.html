Privacy Policy

Last updated: August 8, 2026

ThunderShadow is a browser-based study and error-logging application. Study data is stored locally in your browser by default. Optional Firebase cloud synchronization is available only when you choose to sign in.

1. Local browser data

ThunderShadow stores forms, logged entries, reasoning notes, rules, settings, backup metadata, and deletion records primarily in IndexedDB. The application remains usable without signing in or enabling cloud synchronization.

2. Google sign-in

If you choose Sign in with Google, ThunderShadow uses Firebase Authentication to identify your account and maintain a persistent signed-in session on that browser or installed web app. The application uses your Google account identity, including your Firebase user ID and basic account information such as email address, only to associate your private synchronized ThunderShadow data with you.

ThunderShadow does not request access to your Google Drive files, Gmail, Contacts, Calendar, Google Photos, or other unrelated Google services.

3. Cloud Firestore synchronization

When cloud sync is enabled, ThunderShadow stores synchronized application records in Google Cloud Firestore under a path restricted to your authenticated Firebase user ID. The synchronized content may include the same forms, entries, rules, settings, review history, and deletion metadata that are stored locally in ThunderShadow.

4. Access control

Cloud Firestore Security Rules are configured so an authenticated user can read and write only records stored under that user's own Firebase user ID. Other ThunderShadow users are not granted access to those records.

5. Authentication persistence

Firebase Authentication may store authentication state locally in the browser or installed web app so you can remain signed in after closing and reopening ThunderShadow. Signing out removes that authentication session from the current browser or installed app. Clearing browser/site data can also remove the local session.

6. Sharing, advertising, and AI

ThunderShadow does not sell or rent synchronized user data and does not use it for advertising or data-broker purposes. The application does not send your ThunderShadow study database to an external AI service. GitHub Pages, Firebase, Google Authentication, and Cloud Firestore may process technical information according to their own service policies as required to host, authenticate, and synchronize the application.

7. User control and deletion

You can use ThunderShadow without cloud sync, sign out at any time, delete local data within the application, or clear the site's browser storage. Cloud records associated with your account remain available for synchronization unless they are deleted through ThunderShadow or removed from the Firebase project by the service operator.

8. Security

ThunderShadow uses HTTPS when deployed through GitHub Pages. Firebase Authentication and Cloud Firestore communications are transmitted using encrypted HTTPS connections. You remain responsible for securing access to your device, browser profile, Google account, and exported backup files.

9. Changes

This policy will be updated if ThunderShadow materially changes the data it collects, stores, or synchronizes.

10. Contact

For privacy questions, use the developer contact information published with the ThunderShadow project.
