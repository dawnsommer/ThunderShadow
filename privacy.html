Privacy Policy

Effective: August 7, 2026 · Last updated: August 7, 2026

ThunderShadow is a browser-based study and error-logging application. The application is designed so that your study data is stored locally in your browser by default. Google Drive synchronization is optional.

1. Data stored in your browser

ThunderShadow stores application data such as forms, logged entries, reasoning notes, rules, settings, backup metadata, and deletion records in browser storage, primarily IndexedDB. These data remain on the device/browser profile unless you export them or enable Google Drive synchronization.

2. Google account and Google Drive access

If you choose Connect Google Drive, ThunderShadow requests only the Google Drive drive.appdata scope. This permission allows ThunderShadow to create, read, and update files in the application's private Google Drive appDataFolder.

ThunderShadow does not request permission to browse or read your normal Google Drive files, Google Photos, Gmail, contacts, calendar, or other Google services. ThunderShadow does not request Google profile or email scopes for the Drive-sync feature.

3. How Google user data is used

Google Drive app data is used solely to provide the user-facing ThunderShadow backup and synchronization feature across the user's own browsers/devices. The synchronized package may contain the same ThunderShadow data that the user stores locally, including forms, entries, rules, settings, and deletion records required for conflict-safe synchronization.

4. Storage and authentication

The synchronized ThunderShadow data file is stored in the user's private Google Drive appDataFolder. OAuth access tokens are kept in browser session storage for the active browser session. ThunderShadow does not operate an application server that stores your Google OAuth access token or your ThunderShadow database.

5. Sharing and disclosure

ThunderShadow does not sell, rent, or transfer Google user data to advertisers, data brokers, or other third parties. Google user data obtained through Google APIs is used only to provide the synchronization functionality requested by the user and in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

6. Analytics, advertising, and AI services

The ThunderShadow application does not use Google Drive data for advertising, profiling, or credit-related purposes. The application does not send ThunderShadow study data to an external AI service. The static website host may process ordinary web-request information according to its own hosting policies.

7. User control and deletion

You may use ThunderShadow without connecting Google Drive. You can disconnect Drive synchronization at any time from ThunderShadow settings. Local browser data can be removed by deleting it within ThunderShadow or clearing the site's browser storage. Google Drive app data can also be removed by revoking ThunderShadow's Google account access and deleting the application's stored app data through Google account/Drive controls where available.

8. Data security

ThunderShadow uses HTTPS when deployed through GitHub Pages or another HTTPS host, and Google API requests are transmitted over HTTPS. Users remain responsible for securing access to their device, browser profile, Google account, and exported backup files.

9. Changes to this policy

If ThunderShadow materially changes how it accesses, uses, stores, or shares Google user data, this Privacy Policy will be updated before the changed data use is introduced. Where required, users will be asked to provide new consent.

10. Contact

For privacy questions, contact the ThunderShadow developer using the developer contact information published with the ThunderShadow project and in the Google OAuth consent-screen configuration.

ThunderShadow's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
