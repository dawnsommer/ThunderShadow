ThunderShadow stores synchronized study data only in Google Drive’s hidden appDataFolder. The shared Cloudflare Worker handles Google OAuth and token refresh; the browser stores only a Worker session token and temporary Google access token. IndexedDB remains the primary local database and continues working offline. Reasoning support

Reasoning Pattern Guide

Choose the earliest reasoning operation that failed. Leave blank when no clear pattern applies.

P1 — TASK⇧1

You solved a different question from the one NBME asked.

Use when: The requested output was misunderstood: diagnosis, cause, next step, treatment, prevention, or complication.

Fix: Translate the final question into a 2–4 word command.

P2 — STABILITY⇧2

Failed to classify instability, acuity, or an immediate threat before choosing the pathway.

Use when: Instability, shock, active seizure, severe bleeding, or another immediate threat should have overridden the normal pathway.

Fix: Check for an immediate threat before applying the routine algorithm.

P3 — SEQUENCE⇧3

Recognized the clinical problem but selected the wrong stage of diagnosis or management.

Use when: The diagnosis was understood, but the wrong diagnostic or management stage was selected.

Fix: Locate the current node: stabilize → test → confirm → treat → escalate.

P4 — FRAME⇧4

Built the wrong illness script or added an unsupported assumption before comparing choices.

Use when: The case was represented incorrectly, anchored early, or altered by an unsupported assumption.

Fix: Rebuild the case using only facts supplied in the stem.

P5 — HINGE⇧5

The candidate answers were reasonable, but the decisive discriminator was missed or underweighted.

Use when: The options were plausible, but the decisive discriminator was missed or underweighted.

Fix: Find the single clue the selected answer cannot explain.

P6 — TIMELINE⇧6

The timing, onset, duration, progression, event order, or treatment exposure determined the answer.

Use when: Onset, interval, progression, treatment exposure, or event order determined the answer.

Fix: Write: trigger → interval → presentation.

P7 — MODIFIER⇧7

Knew the usual rule but failed to adjust it for a patient-specific constraint or context.

Use when: Pregnancy, age, comorbidity, contraindication, organ function, or setting changed the usual rule.

Fix: State: normally X; because of Y, choose Z.

Quick decision path

Wrong task? → TASKMissed instability? → STABILITYWrong diagnostic/management stage? → SEQUENCEWrong illness script or unsupported assumption? → FRAMETiming/course decided it? → TIMELINEPatient-specific constraint changed the rule? → MODIFIEROtherwise missed the decisive discriminator? → HINGE

Tie-breaker: When two patterns apply, select the earliest causal failure rather than the final visible mistake.

  • Hypotensive patient sent to CT before resuscitation → STABILITY, not SEQUENCE
  • Understood stability but jumped directly to surgery → SEQUENCE
  • Recent infection caused premature anchoring before comparing clues → FRAME
  • Correct candidate pair but ignored normal complement → HINGE
  • Ignored the two-day interval after infection → TIMELINE
  • Used the standard drug despite pregnancy → MODIFIER

Tie-breaker: when two patterns seem possible, choose the earliest causal failure in your reasoning.

Do not use a reasoning pattern merely to repeat the Error Code.
